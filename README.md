Directory Explanation
- Project
This directory contains the actual content of the project.
- Study
I am very new to a lot of these subjects. This folder is a cloud back up study folder dedicated towards learning tools like OpenGL, CMake, Vulkan, QT, and more.

The following is a collection of games I'm making to practice on my new programming skills! 
It's a GUI program written in OpenGL with light 3D usage. This is an attempt at understanding graphics development/pipeline and working on a large-scale project with many files.
This is developed and packaged on first and foremost linux but other operating system support is planned!

Feel free to make an issue on any bugs or criticisms!
